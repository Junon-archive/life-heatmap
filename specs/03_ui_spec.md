# 03. UI/UX 명세

## 1. 화면 구성

앱은 사실상 단일 페이지 + 오버레이들로 구성된다.

```
┌──────────────────────────────┐
│ 헤더: 앱 이름 · 동기화 상태 · ⚙️  │
│ (모바일) 히트맵 탭 인디케이터      │
├──────────────────────────────┤
│                              │
│   히트맵 뷰 (메인, 즉시 표시)     │
│   - 모바일: 1개 전체폭,          │
│     좌우 스와이프로 전환          │
│   - 데스크톱(≥768px): 2~3개      │
│     나란히 그리드                │
│                              │
├──────────────────────────────┤
│ (히트맵 카드 하단) 통계 요약 줄    │
└──────────────────────────────┘
```

- **오버레이**: 칸 편집기(바텀시트/팝오버), 설정 뷰, 통계 뷰, 범례 패널, 연도 점프 메뉴.
- 라우팅 불필요(해시 라우팅으로 설정/통계 뷰 정도만 구분해도 됨). 첫 페인트에서 히트맵이 바로 보이는 것이 최우선.

## 2. 히트맵 카드

```
┌ 기상/출근            🔥 12일  ⓘ ┐   ← 이름 · (streak형만) 현재 연속일 · 범례 아이콘
│      일 월 화 수 목 금 토        │   ← 요일 헤더 (고정)
│ 7/5~   ▨ ▨ □ ▨ ▨ ▨ ▨        │
│ 7/12~  ▨ ▨ ▨ □ ▨ ▨ ▨        │   ← 위 = 과거, 아래 = 최신
│ …                             │
│ 8/16~  ▨ [오늘] · · · · ·      │   ← 오늘 이후는 미래 스타일
└───────────────────────────────┘
```

- 행 라벨: 전역 토글에 따라 `7/5~`(주 시작일, 연도 바뀌면 `'27 1/3~`) 또는 `W28`. 토글 버튼은 요일 헤더 왼쪽 상단 구석에 작게.
- **초기 표시 범위**: 최근 12주. 위로 스크롤 시 과거 주를 24주 단위로 추가 로드(가상 스크롤까지는 불필요, 연 단위 수백 행은 DOM으로 충분).
- **초기 스크롤 위치**: 오늘이 포함된 행이 카드 보이는 영역의 **하단 약 1/4 지점**에 오도록 — 위쪽에 과거 8~10주가 함께 보인다. 오늘 행을 최상단에 두지 말 것(R-20).
- **연도 점프**: 카드 우상단 or 라벨 열 상단의 연도 버튼 → 연/월 목록 → 해당 주로 스크롤.
- 모바일 스와이프: 수평 스와이프로 이전/다음 히트맵. 헤더 아래 점(dot) 인디케이터. 세로 스크롤과의 제스처 충돌 방지(수평 이동량이 우세할 때만 전환).

## 3. 칸(Cell) 렌더링

칸은 rounded-square(반경 4px), 크기는 컨테이너 폭 기준 유동(모바일 7칸 기준 약 40~44px, 간격 4px — 탭 타깃 최소 40px 확보).

레이어 순서 (아래→위):
1. **바탕**: 상태별 배경 (§3.1)
2. **채우기**: 빗금(45° 스트라이프) 또는 단색 (§4 팔레트)
3. **마크**: 중앙에 숫자 또는 기호(○/X/★) — 칸 크기의 ~60%
4. **테두리 강조**: 2px 링 (마크 색과 동일 계열)
5. **오늘 표시 / 마일스톤 이펙트** (최상위)

### 3.1 날짜 상태별 바탕 (R-21)
| 상태 | 스타일 |
|---|---|
| 지난 날짜, 기록 없음 | 옅은 회색 바탕 + 중앙 2px 회색 점 (기록 안 함이 명시적으로 보임) |
| 오늘 | accent 색 2px 아웃라인 (기록 여부 무관, 항상) |
| 미래 | 바탕 투명도 40%, 점 없음. **탭 가능**(잠금 금지, R-14) |
| 기록 있음 | 채우기/마크가 바탕을 대체 |

### 3.2 유형별 추가 렌더링
- **streak · auto 모드**: 마지막 실패 이후의 지난 날짜는 엔트리가 없어도 `baseStyle`(빗금/단색)·`baseColor` 그라데이션으로 자동 채색. 수동 표기가 있으면 수동 표기(양식·색) 우선.
- **streak · manual 모드**: fill이 있는 날만 채색.
- 두 모드 모두 **수동 채움 포함 모든 채움의 강도는 그 날의 streak 단계를 따른다**(D-11).
- **그라데이션 5단계**: streak 일수를 `levels`(기본 [1,3,7,14,30])에 대입 → `baseColor`의 투명도 25% / 40% / 55% / 75% / 95%.
- **마일스톤 칸** (streak N일차가 `milestones`에 포함): accent 2px 테두리 + 부드러운 glow(box-shadow), 장기 목표 달성감을 주되 과하지 않게. 탭하면 "N일 달성" 툴팁.
- **실패 체크 칸**: 채우기(자동 그라데이션 포함) 없이 렌더 — 표기가 없으면 "지난 날짜, 기록 없음"과 동일하게 보인다 (R-11, D-4). 마크·테두리 강조는 표기했다면 그대로 표시(D-10). 칸 편집기를 열면 실패 체크 상태가 보인다.
- **conditional**: `value` 입력 시 `rules` 첫 매칭의 색으로 자동 채색. `showValue`가 true면 수치를 마크 위치에 표시(이때 별도 마크는 편집기에서 비활성).

## 4. 디자인 토큰

### 4.1 팔레트 (6색 — 채우기·마크 공용)
| 키 | HEX | 비고 |
|---|---|---|
| `blue` | `#3B82F6` | 종이 기록의 파란 펜 대응 |
| `rose` | `#F43F5E` | 종이 기록의 분홍/자주 펜 대응 |
| `green` | `#22C55E` | |
| `amber` | `#F59E0B` | |
| `violet` | `#8B5CF6` | streak 기본 그라데이션 색으로 추천 |
| `slate` | `#64748B` | 중립 |

- 빗금 = 해당 색 45° 스트라이프(스트라이프 폭 3px, 간격 3px, 색 투명도 80%). 단색 = 해당 색 투명도 75% (마크 대비 확보).
- 마크 기본색 = `#334155`(진회색), 팔레트로 변경 가능.
- UI 크롬(버튼·헤더)은 무채색 위주로 하고 색은 데이터에만 쓴다 — "군더더기 없이"의 핵심.

### 4.2 기타
- 바탕: `#F8FAFC`, 카드: `#FFFFFF` + 1px `#E2E8F0` 테두리(그림자 최소). UI 회색 톤은 전부 쿨 그레이(slate) 계열 — 텍스트 `#0F172A`/`#64748B`/`#94A3B8` (D-13).
- 글꼴: 시스템 폰트 스택(`-apple-system, "Pretendard Variable", sans-serif` 순). 숫자 마크는 tabular-nums.
- 다크 모드: v1 범위 외 (백로그).
- 애니메이션: 편집기 열림/닫힘, 채우기 적용 시 120~180ms 페이드 정도만.

## 5. 칸 편집기 (핵심 인터랙션)

칸 탭 → 모바일은 **바텀시트**, 데스크톱은 칸 옆 **팝오버**. 열리는 즉시 해당 날짜가 상단에 표시(`8월 16일 (일)`). 모든 변경은 **탭 즉시 저장**(저장 버튼 없음), 바깥 탭/스와이프 다운으로 닫기.

날짜 표시줄 우측에 **✕ 닫기 버튼**을 둔다 — 모바일에서 바텀시트가 화면 하단을 가려, 가려진 날짜를 선택하려면 명시적으로 닫을 수단이 필요함(D-15).

구성(위에서부터):
1. **채우기**: [없음] [빗금] [단색] 세그먼트 + 6색 스와치 한 줄.
2. **마크**: [없음] [123] [○] [X] [★] — `123` 선택 시 인라인 숫자 키패드(0~99). 마크 선택 시 색 스와치 한 줄 노출(기본 진회색).
3. **테두리 강조**: 토글.
4. **유형별 행**:
   - streak: **[실패 체크]** 토글 — 빨간 계열의 명확한 구분. 켜면 채우기 컨트롤만 비활성화(채우기와 배타). 마크·테두리는 계속 사용 가능(D-10).
   - conditional: 수치 입력 필드(+ 단위 표시) — 입력 즉시 규칙 색 미리보기.
5. **지우기**: 이 날짜의 모든 표기 제거.

같은 카드의 다른 칸을 탭하면 편집기가 닫히지 않고 대상 날짜만 바뀐다(연속 입력 — 과거 데이터 수기 입력 시 중요).

## 6. 설정 뷰 (⚙️)

1. **히트맵 관리**: 목록(위/아래 버튼으로 순서 변경) / 추가 / 이름 변경 / 보관 / 삭제(확인 필수, "삭제하면 복구 불가 — 내보내기 권장" 안내).
   - 히트맵 편집 화면: 이름, 유형, streak 설정(모드 auto/manual, 기본 색, 마일스톤 목록 편집, 그라데이션 단계), conditional 규칙 편집(구간+색 행 추가/삭제), 범례 편집(표기 샘플 + 라벨 텍스트).
2. **표시**: 행 라벨 토글(날짜 범위/주 번호).
3. **동기화**: 동기화 코드 생성(랜덤 24자+) / 입력 / 해제, 마지막 동기화 시각, 수동 동기화 버튼. 코드 안내 문구: "이 코드를 아는 기기만 데이터를 공유합니다. 안전한 곳에 보관하세요."
4. **백업**: JSON 내보내기 / 가져오기(병합·전체 교체 선택, 교체는 확인 대화상자).

## 7. 통계 뷰 (설계 위임분 — 확정안)

각 히트맵 카드의 통계 요약 줄(아래) + 카드 헤더의 확장 진입.

- **카드 하단 요약 줄** (항상 표시, 한 줄):
  - streak형: `🔥 현재 12일 · 최고 47일`
  - basic/conditional: `이번 달: ▨ 71% · ○ 8 · X 2` (그 히트맵에서 실제 사용된 표기만 아이콘으로 나열)
- **통계 확장 뷰** (카드에서 진입, 오버레이):
  - 기간 단위 토글: **월별 / 분기별**.
  - 표기별 집계 테이블: 행 = 기간(최신 위), 열 = 채움 일수(%) · 사용된 기호별 일수 · 숫자 마크 합계 · (conditional) 수치 평균.
  - 각 % 값 옆에 CSS 수평 바(팔레트 색, 라이브러리 없이 div로). 차트 라이브러리 도입 금지 — 과설계.
  - streak형 추가: 현재/최고 streak, 실패 횟수(월별), 마일스톤 달성 이력.
  - 의미 라벨은 붙이지 않는다(§원칙 "의미 비강제") — 표기 아이콘 그대로 열 머리글로 쓴다. 범례를 등록했다면 열 머리글 옆에 작게 표시(범례 패널과 동일하게 기본 숨김, 토글로).

## 8. 범례 패널 (ⓘ)
- 카드 헤더의 ⓘ 아이콘 탭 → 작은 팝오버로 해당 히트맵의 범례 목록(표기 샘플 + 라벨).
- **기본은 어디에도 노출되지 않는다**(위장 유지). 등록된 범례가 없으면 아이콘도 숨김.

## 9. 연간 보기 (R-30, D-12)

- 진입: 헤더의 **「기본 | 연간」 세그먼트 토글**(현재 보기가 강조되어 상태가 즉시 읽힘 — 아이콘 단독은 직관성 부족으로 교체, D-15). 새로고침 시 항상 기본 보기.
- 상단에 범위 선택 세그먼트: **[최근 1년] [2026] [2025] …** (연도는 전체 히트맵의 기록 시작 연도부터). 최근 1년 = 마지막 열이 이번 주인 trailing 53주. 연도 = 1/1이 속한 주 ~ 12/31이 속한 주, 범위 밖 날짜 칸은 빈 자리로 둠.
- 각 히트맵 블록: `이름 · (streak형) 🔥 현재 N일` 헤더 + 그리드 + 연 통계 한 줄.
- 그리드: 행 7(일~토), 열 = 주. 열 폭은 컨테이너를 균등 분할해 **가로 스크롤 없음**. 행 라벨 Mon/Wed/Fri, 월 라벨은 달이 바뀌는 열 위에 영문 약칭.
- 칸: `cellVisual` 재사용 — 기본 보기와 동일 규칙을 **compact 모드**로 축소 렌더(D-14). 열 트랙은 반드시 `minmax(0, 1fr)`(1fr만 쓰면 월 라벨의 min-content 때문에 좁은 화면에서 열이 찌그러짐 — 실기기 버그 이력). 채우기(빗금/단색)와 기호(◯✕★ SVG)는 그대로 축소, **숫자·수치 텍스트는 마크 색의 작은 점으로 대체**(5px 칸에 텍스트 불가). 테두리 강조 1px, 마일스톤 glow 축소, 지난 빈칸의 점 숨김, 오늘 아웃라인 1px. 월 라벨은 칸 위로 흘러넘치게(overflow) 둔다.
- 인터랙션: 편집 없음. 칸 탭 → 기본 보기로 전환하며 해당 히트맵의 그 주로 스크롤.
- 연 통계 한 줄(§7 요약줄의 연간판): 일반/조건부 `▨ N일 (P%) · ◯ n · ✕ n · ★ n · № 합 · 평균 x` 중 사용된 표기만 / streak형 `🔥 현재 N일 · 최고 N일 · 실패 n회`. 분모는 범위 중 오늘까지 지난 일수.

## 10. 빈 상태 & 온보딩
- 첫 방문(히트맵 0개): 중앙에 "+ 히트맵 만들기" 버튼과 유형 3종의 한 줄 설명만. 튜토리얼·샘플 데이터 없음.
- 새 히트맵 생성 플로우: 이름 입력 → 유형 선택(각 유형 카드에 1줄 설명) → (streak면 auto/manual 선택) → 생성. 나머지 설정은 기본값으로 시작해 설정 뷰에서 수정.
